# Marquee

[Marquee](https://github.com/biohazardious/Marquee) is a MAME library manager in the shape of Sonarr:
pick the games you want, fetch only those through your own download client, and keep a
categorised, verified library - with an EmulationStation gamelist - current across MAME releases.

Mount the same torrent folder your download client writes to as the downloads storage.
The library can be a folder on this system, or a console reached over SMB, FTP or SFTP,
which is set in Marquee's own settings.
